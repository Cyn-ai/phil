## Lesson → edit

Playbook, utterance section: add a **truncated-transcript rule**. When an
analogue transcript covers less than about 60% of the speech, that analogue
is not a zero for an absent word, and its count is a floor for a count
threshold. For an absent word, the analogue counts only toward the observed
fraction of the speech. For a count, scale it AND widen the range rather
than centring on it. If the No-side read rests mainly on truncated
partials, record est within 0.10 of the mid and put the raw partial
read in the note as "partial view: X". Evidence: c80e6add58d8 and
ad6dd7605658, both -$5 CF, one occasion. This is provisional recording
discipline, the same shape as the 2026-09-26 liquid-mid rule.
